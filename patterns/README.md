## Learning Roadmap

1. Start with solid squares and simple left triangles.
2. Practice repeated row values and increasing column values.
3. Add right alignment using leading spaces.
4. Move to pyramids with odd-width formulas.
5. Study palindrome patterns using increasing and decreasing loops.
6. Finish with diamonds and hollow patterns that combine symmetry and conditionals.

## Revision Checklist

- [ ] I can identify what the outer loop controls.
- [ ] I can calculate spaces for right-aligned and centered patterns.
- [ ] I can explain why pyramid star counts use odd numbers.
- [ ] I can trace counters that continue across multiple rows.
- [ ] I can dry-run palindrome patterns row by row.
- [ ] I can separate upper and lower halves of diamond patterns.
- [ ] I can explain boundary conditions in hollow patterns.
